A Figma plugin: design one ad, get every other size, plus linked language versions.

Still in development. This tool is being built and tested, and its output can be wrong: a cropped face, text that doesn't fit, a missing layer. Check every generated size by eye against the design before you use, export or hand anything off. The automated checks help, but they don't replace your review. Provided as is.

First install

  1. Unzip the download. You get a folder called Static Recompose.
  2. Move that folder somewhere permanent, for example Documents/Figma Plugins. Figma runs the plugin from this folder, so don't leave it in Downloads.
  3. In the Figma desktop app: Plugins → Development → Import plugin from manifest… and pick manifest.json in that folder.
  4. Run it from Plugins → Development → Static Recompose: Resize to all sizes or Localize.
You need the design's fonts installed. If any are missing, the plugin says which.

Updating

When a new version is out, the plugin shows a blue notice at the top of its panel. Your version is at the top right.

  1. Download the new version above and unzip it.
  2. Drag the files from the new folder into the folder you installed the plugin from and choose Replace.
  3. Close and reopen the plugin. No need to import it again.

Which designs it works on

Works well

  • A photo on one side, and the logo, headline and button on the other
  • One headline and one button
  • Any brand, colours, fonts or sizes

Not yet

  • Text over a full-bleed photo
  • No photo, or a centred product shot
  • Photo on top, copy below
  • Extra lines (subheadline, legal) — added by hand

Every size is labelled pass, review or blocked. Look over every size before handing off.
